# TokoQu - Build APK via GitHub Actions

Project ini adalah aplikasi React/Vite dari Google AI Studio yang dibungkus menjadi aplikasi Android menggunakan Capacitor.

## Build otomatis

1. Upload seluruh isi project ini ke repository GitHub.
2. Pastikan branch utama bernama `main`.
3. Buka tab **Actions** di GitHub.
4. Pilih **Build TokoQu APK**.
5. Klik **Run workflow** jika belum otomatis berjalan.
6. Setelah selesai, buka hasil workflow dan download artifact **tokoqu-apk**.
7. Di dalam ZIP artifact terdapat `app-debug.apk`.

Icon Android berasal dari `assets/icon.png`.
